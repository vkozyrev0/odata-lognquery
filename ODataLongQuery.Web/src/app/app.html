How to call the service

Each wait-mode page sleeps the delay (sent as X-Demo-Wait-Delay-Milliseconds = delay × 1000; @if (demoConfig(); as cfg) { service default {{ cfg.waitQueryDelayMilliseconds / 1000 }}s } @else { service default 4s }). If page delay is greater than wait, the original request returns 202 and you poll. If page delay is less than or equal to wait, you get 200 with no monitor. Later pages use wait=min(N, 5).
